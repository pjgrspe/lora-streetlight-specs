The system

Four kinds of box, three links. The server talks only to the Master, over a wire. The Master talks to one Slave gateway per section over tier 1. Each Slave runs its own small radio network, its cell, with up to 60 devices: one LED driver/monitoring device per pole plus the section's energy meter. The number of sections is configured (1–14).

Channels

Fourteen 125 kHz channels on a 200 kHz raster fill 915–918 MHz. Tier 1 takes the two band edges, so the primary and standby radios are as far apart as possible. Each section gets two channels 1.2 MHz apart. Up to six sections fit without reusing a pair.

One cycle

Everything repeats every 120 s. Nobody polls: each Slave reports in its own tier-1 slot, and each device reports in its own cell slot. A gateway can't receive while it transmits, so each Slave starts its cell cycle early by a fixed offset. That puts its tier-1 slot exactly in the cell's quiet window, when none of its devices are transmitting.

A command, end to end

An operator dims a whole site to 50%. The command never waits for a radio round trip on the wire, never goes device by device, and every lamp switches at the same second. Confirmation arrives later, in the reports the devices send anyway.

Device lifecycle

This is the part the device-role library runs for you (03 §2, §5, §11). The lamp never depends on it: in every state the device follows its own sunrise/sunset schedule, and with no trusted time it holds the lamp at 100%.

The frame

One format for both tiers and all roles: an 8-byte header, the payload, a 4-byte MIC. Little-endian throughout. The payload is encrypted (except join requests, beacons and heartbeats, which are signed only), and the MIC is checked before anything is decrypted or parsed.

When things fail

The rule behind every row: if a failure leaves the lighting in doubt, the lights go to 100% at night. Each box can lose the one above it and keep its lamps on schedule, so no single failure darkens a road. Spec 05 is the signed version of this table.

Who builds what

The interfaces between people are the specs. The device developer never implements the radio protocol: they link the device-role library and handle DALI, measurement, the schedule and persistence around it.
